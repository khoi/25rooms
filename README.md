# A small light, somewhere else

Animated isometric rooms across two collections built with threejs

This adaptation by [khoi](https://github.com/khoi) builds on [a small light, room by room](https://a-small-light-three.vercel.app/). 

## Collections

- **01 · Somewhere else** The new 25 rooms build by GPT Astra 6 xhigh.
- **02 · Original** preserves the original 25 room designs in the new viewer.

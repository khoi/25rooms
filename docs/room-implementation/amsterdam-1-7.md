# Amsterdam rooms 1–7: implementation review

Reviewed against `docs/amsterdam-rooms.md` on 2026-09-18. Each room retains the 12-by-12 footprint and uses the existing canvas palette and renderer. This range owns seven modules in `dist/artwork/cities/amsterdam/`.

The prototype comparison is `/tmp/amsterdam-1-7/prototype.png`. It places the cargo room beside the original greenhouse and the bread stall beside the original press at equal 900-pixel widths. The first cargo version had sparse side and foreground areas. Its revision adds fitted boot storage, a carrier net, paired reflectors, a preparation bench, a matching child bag, and a threshold drain. `/tmp/amsterdam-1-7/cargo-revised.png` records that revision. The original scenes still have more varied wear and smaller incidental stories. This review does not claim that the new range exceeds them.

Every room was inspected at 220-pixel collection width, 800-pixel normal width, and 1400-pixel close width. Each intended still pose and four animation phases were also inspected. Evidence lives outside the repository in `/tmp/amsterdam-1-7/`. The final collection view is `collection.png`. Each module stem has `-normal.png`, `-close.png`, and `-phases.png` evidence files in that directory. The phase sheets show time 0, 30 percent and 70 percent of the loop, and one millisecond before the end.

The strongest overall room is `cargo-canopy.js`: the moving greenhouse-shaped roof, bicycle frame, and family preparation details form one readable story. `canal-step.js` has the clearest architectural progression, and `canal-bindery.js` has the richest fitted storage.

Validation used `/tmp/amsterdam-1-7/check.mjs`, adapted from the repository's coordinate checks. All seven modules passed 77 static and animated phase executions, including both sides of each loop boundary. `/tmp/rooms-200-render/check-amsterdam-loop.mjs` compares the actual `RoomPainter` output at time 0 and the declared duration. All seven matched pixel for pixel at zero boil. Figure clip names are unique to these scenes. The renderer completed every evidence capture without import or drawing errors.

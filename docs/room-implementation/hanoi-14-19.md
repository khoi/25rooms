# Hanoi rooms 14–19 implementation review

Review date: 2026-09-18. These six modules implement the corresponding entries in `docs/hanoi-rooms.md`. Each room has a 12-by-12 footprint, an explicit loop duration, and a selected still time. The rear architectural boundaries follow the renderer's `i=0` and `j=0` edges.

The review used the real `RoomPainter` through `/tmp/rooms-200-render/render.mjs`. All six rooms were inspected at 220-pixel collection width, 800-pixel normal width, and 1400-pixel close width. The close images use each room's still time. Phase sheets include the initial pose, each main beat, the settling pose, and both sides of the loop boundary.

The first comparison, `/tmp/hanoi-14-19/comparison.png`, places the drafting room and the pedal store beside the original `library` and `press` at matching widths. Source study also included `kitchen`. The original rooms have denser secondary detail and stronger localized lighting. This implementation uses clearer individual mechanisms and quieter access areas. The comparison does not support a claim that these rooms exceed the originals.

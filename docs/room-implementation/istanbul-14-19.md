Source study also covered the original library. These originals have denser fine construction in several areas; this record does not claim that the new rooms surpass them.

`/tmp/check-istanbul-14-19.mjs` imports the six modules directly and checks finite coordinates in static and live drawing calls. It passed for every 0.4-second sample and the values immediately before, at, and after each loop boundary. Seven phase renders per room cover the preparation, motion, pause, return, and boundary. Pixel comparison of the rendered artwork at time zero and the declared duration found no differing channels. Labels were excluded from that comparison.

The final source passed `git diff --check`. Browser navigation, integrated collection order, and reduced-motion selection remain part of root integration. No shared helper, registry, hosting file, or application file was changed by this worker.

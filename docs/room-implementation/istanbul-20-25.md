## Validation

`node /tmp/istanbul-20-25/validate.mjs` imports the six modules directly and checks their exact IDs, metadata, static drawing, and finite coordinates. The 60 animation samples include the beat boundaries, still times, and both sides of each loop boundary.

`node /tmp/istanbul-20-25/phases.mjs` uses the real painter. For every room, the pixels at zero seconds and one full loop are identical with drawing boil held at zero. The same script generates the six phase sheets listed above.

The collection sheet, normal views, all six close views, and all six phase sheets were inspected. Fixes addressed opaque window glass, projector placement, lamp-face overlap, guitar height, cushion contact, and return-walk timing. The art contains no lettering. No shared helpers, registry files, navigation files, or existing rooms changed in this assignment.

Browser integration, collection ordering, and commit ownership remain with the coordinating agent. The native review establishes the artwork and animation behavior; it does not replace the integrated browser check.

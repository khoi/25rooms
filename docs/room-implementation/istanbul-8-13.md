# Istanbul rooms 8–13 implementation review

Reviewed 18 September 2026 with the shared native canvas harness using the application's actual `RoomPainter`. The six modules keep the 12 × 12 footprint and expose the exact brief IDs, loop duration, and intentional still time. Scene drawing and hand-contact rigs are local to each module. No shared files were edited.

The first comparison used the original print shop and library at 800 pixels per room. The kitchen comparison was also inspected. The original library and print shop have more tightly occupied wall systems and stronger local shadow hierarchy. These six new rooms prioritize different working silhouettes and retain larger clear routes. This review does not claim that they exceed the originals.

All six were inspected at collection width 220, normal width 800, and close width 1400. Normal and collection sheets are `/tmp/istanbul-8-13/all-normal.png` and `/tmp/istanbul-8-13/collection.png`. Each close image and eight-state phase sheet was opened and inspected. The phase sheets include preparation, contact, open state, supported return, the final pose, and both sides of the loop. The finite-coordinate check exercised 538 animation frames. At zero drawing boil, the complete canvas PNG hashes at time zero and each exact loop duration agree for all six rooms.

# London rooms 14–19 implementation review

These six modules preserve the 12 × 12 footprint and drawing palette. Each exports a complete room, a closed loop duration, and a deliberate still time. No shared helpers, collection registration, existing artwork, or hosting files were changed by this worker.

The shared native renderer ran the real `RoomPainter`. Every room was viewed at 220px collection size, approximately 800px normal size, 1400px close size, and its selected still. Seven motion phases per room cover the first pose, each principal beat, the closing pause, and both sides of the loop. The direct drawing check exercised six static scenes and 66 live frames with finite-coordinate checks. Additional midpoint images inspect the lifting map and hatch.

Evidence is stored outside the repository at `/tmp/london-14-19/`. In the table, each slug has `<slug>-800.png`, `<slug>-1400.png`, and `<slug>-phases.png`; `collection.png` contains all six at 220px. `originals.png` contains the original map, library, and press at matching 800px widths. The initial stage/press comparison is `/tmp/london-14-19-stage-compare.png`.

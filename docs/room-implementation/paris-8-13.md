# Paris rooms 8–13 implementation review

The six modules use the existing canvas renderer, a 12-by-12 footprint, and room-specific figure clips. Each module declares its loop duration and still time.

The review used `/tmp/rooms-200-render/render.mjs`, which runs `RoomPainter`. Every room was inspected at 220 pixels, 800 pixels, and 1400 pixels. Beat sheets show the initial pose, each main transition, the closing pause, and the loop endpoint. Direct drawing checks covered 19 times per room, including negative time, both sides of the loop boundary, and the still time. A separate raster check confirmed identical pixels at zero and the exact loop duration for all six rooms.
